# Module graph

Generated by [scripts/module_graph.sh](../scripts/module_graph.sh) from
`go run ./tools/importgate --modules .`: the module graph this repository's own
Go sources measure today. Nothing here is kept by hand, and the direction of
every row is computed from the order below, never declared. Read it beside
[the import gate](../tools/importgate/README.md), which refuses a production
import that climbs the order and refuses a module the order does not place.

## The order

Rank is position. The order belongs to the gate, so a layer name means the same
thing in the kernel, the catalogue and a product repository; each repository
assigns only its own modules, in its own `scripts/imports-layers.txt`.

| Rank | Layer | |
| --- | --- | --- |
| 0 | `platform` | needs no account, no role and no person; works over a tenant id and values |
| 1 | `identity` | owns the account, the tenant record, a person's identity, or the channel the platform reaches a person through |
| 2 | `generic` | a reusable domain capability composed over the two layers below |
| 3 | `product` | the module's reason is an application-facing surface |
