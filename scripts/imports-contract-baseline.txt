# Production contract imports the frozen public API keeps in place. One row per
# edge: the contracts package's directory, the exact dependency it imports, and
# the exported name at the release line's frozen commit that carries it. The gate
# refuses a row whose import has gone, so this list only shrinks; moving an edge
# out is the release that can break the surface, not this one. See
# tools/importgate/README.md and docs/COMPATIBILITY.md.
